# 🎨 React Counter App with Animated UI

A dynamic Counter Application built with **React**, featuring advanced CSS animations, state management, and a modern "Glassmorphism" UI design. 

This project is version controlled with **Git** and deployed live on **Vercel**.

## 🚀 Live Demo
### [👉 Click here to view the Live App](https://divagar199.vercel.app)

---


## ✨ Key Features

- **State Management:** Utilizes React's `useState` hook for seamless UI updates.
- **Safety Logic:** Prevents the counter from going below zero with conditional logic.
- **Conditional Rendering:** Displays a "Minimum limit reached" warning dynamically when the count is 0.
- **Advanced CSS & UI:**
  - **Animated Background:** A continuous, flowing gradient background using CSS Keyframes.
  - **Gradient Text:** The counter number features `background-clip: text` to match the moving background animation.
  - **Glassmorphism:** The main card features a translucent, blurred backdrop effect.
